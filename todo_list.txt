로직은 다음과 같음
1. Spotify에서 제공하는 Key + Mode를 이용해 해당 노래의 음계를 결정
2. 결정된 음계에 3화음 구성 규칙을 적용해 해당 음계에서 생성할 수 있는 7개의 기본 코드를 결정
3. 생성된 7개의 코드를 기반으로 실제 대중음악에서 자주 사용되는 **대표 코드 진행 30개(3코드 진행 20개, 4코드 진행 10개)**를 생성
4. 입력곡과 후보곡의 코드 진행을 각각 비교하는데, 각 코드를 구성하는 3개의 음으로 분리한 후 Tonnetz 그래프와 Dijkstra 알고리즘을 이용해 음 사이의 거리를 계산하고 평균을 내어 코드 진행 간 거리를 산출
5. 3코드와 4코드 진행의 길이가 다른 경우 4코드 진행에서 코드 하나를 제외한 경우들을 비교하고 패널티를 부여하며, 대중음악에서 자주 사용되는 대표 코드 진행에 대해서는 별도의 가중치를 적용
6. 산출된 코드 진행 간 거리들을 가중 평균하여 노래 간 최종 거리를 계산하고, 거리가 가까운 순서대로 정렬하여 사용자가 지정한 비율만큼 추천곡을 선별
